#🤖 AI Personal Assistant
"Meet your AI-powered productivity companion — designed to simplify your daily life.
From scheduling tasks and setting reminders to delivering smart news summaries, it keeps you ahead of the day."

📌 Project Overview
A smart AI-powered web app that helps you schedule tasks, set reminders, and receive daily news summaries — all in one clean, responsive interface.

🌟 Key Benefits
⚡ Save time with AI-curated news summaries
🗓️ Never miss a task or deadline
🔔 Smart reminders to keep you on track
📱 Works on all devices — mobile & desktop

🛠️ Tech Stack
TechnologyUseReact.jsFrontendFirebase AuthAuthenticationFirestoreDatabaseFirebase HostingDeploymentTailwind CSSStyling

✅ Prerequisites
Make sure you have installed:
Node.js (v14+)
npm
Firebase Account

⚙️ Installation
bash# 1. Clone the repo
git clone https://github.com/barais111/Personal_Assistant_Project.git

# 2. Go to project folder
cd Personal_Assistant_Project

# 3. Install dependencies
npm install

🔐 Environment Setup
Create a .env file in the root folder:
envREACT_APP_FIREBASE_API_KEY=your_api_key
REACT_APP_FIREBASE_AUTH_DOMAIN=your_auth_domain
REACT_APP_FIREBASE_PROJECT_ID=your_project_id
REACT_APP_NEWS_API_KEY=your_news_api_key

▶️ Run the App
npm start

🚀 Deploy to Firebase
bashnpm run build
firebase deploy
